# SpacePlan Icon Library

A beginner-friendly Vite application using plain JavaScript. PixiJS draws the floor-plan grid, while one centralized SVG registry supplies accessible workplace icons to the library, marker type picker, and floor-plan markers.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install` in this folder.
3. Run `npm run dev`.
4. Open the local address printed in the terminal.

## Build and publish

Run `npm run build`. The generated `dist` folder can be published with GitHub Pages. In GitHub, open **Settings → Pages**, choose **GitHub Actions**, and use GitHub's suggested Vite workflow.
